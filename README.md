# 2HOUSS MUSIC

> **J Lofton · James Earl Lofton — Chicago House Pioneer, est. 1983.**

An awwwards-grade, motion-rich single-page tribute experience for **2Housspeople / 2HoussMusic**, the Chicago house project founded in 1987 by DJ, producer, songwriter and House Music Pioneer **J Lofton** — originally of **2 House People**, with releases on **Trax Records**, **Neco Records**, **Olio Entertainment** and **Gherkin Records**, now based in Phoenix, AZ.

## Stack

- **Vite** (vanilla JS, no framework)
- **GSAP** + **ScrollTrigger** — scroll & timeline animation
- **Lenis** — buttery smooth scrolling
- **Canvas 2D** — particle field / floating ember system
- Custom cursor, magnetic buttons, split-text reveals, marquees, grain, preloader — all hand-rolled

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Deploy

Connected to Vercel — push to `main` or run `vercel --prod`.
